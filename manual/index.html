Keyword index

All keywords and functions in the ABL programming language.

Back to the language reference

!
Inverts every bit of a signed 32-bit integer as an alias for NOT.

!=
Compares two values for inequality.

*
Multiplies two numbers.

+
Adds numeric values or concatenates text.

-
Subtracts numbers or negates a numeric expression.

/
Divides one number by another.

<
Tests whether one value is less than another.

<=
Tests whether one value is less than or equal to another.

<>
Compares two values for inequality.

=
Assigns a value or compares two values for equality.

>
Tests whether one value is greater than another.

>=
Tests whether one value is greater than or equal to another.

?
Prints expressions as an abbreviation for PRINT.

ABS()
Returns the absolute value of a number.

AND
Combines two signed 32-bit integers using bitwise AND.

ASC()
Returns the character code of the first character in a string.

ATN()
Returns the arctangent of a number in radians.

BLOAD
Loads binary data from a file into session memory.

BLOCKSPRITECOLLIDE()
Reports whether two block sprites occupy the same position.

BLOCKSPRITEX()
Returns the horizontal position of a block sprite.

BLOCKSPRITEY()
Returns the vertical position of a block sprite.

BSAVE
Saves a range of session memory to a binary file.

CHR$()
Returns the character corresponding to a character code.

CLS
Clears the screen and optionally selects the number of columns.

COLOR
Changes the background, text or border color.

CONT
Resumes a numbered program paused by STOP or Ctrl+C.

COS()
Returns the cosine of an angle in radians.

CREATEBLOCKSPRITE
Creates a block sprite with a character, color and position.

CURSOR
Shows or hides the blinking text cursor during program execution.

DATA
Stores literal values for subsequent READ statements.

DATAPOINTER()
Returns the current position in the program's DATA values.

DEF
Defines a numeric function using FN.

DELETEBLOCKSPRITE
Deletes one block sprite or all block sprites.

DIM
Creates an array with specified inclusive upper bounds.

ELSE
Introduces the alternative branch of an IF statement.

END
Ends program execution without retaining a continuation.

EXP()
Returns e raised to a specified power.

FN()
Calls a user-defined numeric function.

FOR
Starts a counting loop with a limit and optional step.

GO
Introduces the spaced GO TO and GO SUB forms of jump statements.

GO SUB
Calls a subroutine as an alternative spelling of GOSUB.

GO TO
Jumps to a target as an alternative spelling of GOTO.

GOSUB
Calls a subroutine and saves the return position.

GOTO
Jumps to a target line or label.

HARD
Makes RESET clear the stored program as well as runtime data.

IF
Executes a branch according to a condition.

INPUT
Reads values from the keyboard into variables or array elements.

INT()
Converts a number to a 32-bit integer by truncating toward zero.

LEFT$()
Returns a specified number of characters from the start of a string.

LEN()
Returns the number of characters in a string.

LET
Assigns a value to a variable or array element.

LIST
Displays all or a selected range of stored program lines.

LOAD
Loads a BASIC source file into program memory.

LOG()
Returns the natural logarithm of a positive number.

MID$()
Returns a substring from a specified position.

MOVEBLOCKSPRITE
Moves a block sprite to an absolute position.

NEW
Deletes the stored program and clears runtime data.

NEXT
Advances a FOR loop or finishes it when its limit is passed.

NOT
Inverts every bit of a signed 32-bit integer.

OFF
Disables the blinking text cursor when used with CURSOR.

ON
Selects a GOTO or GOSUB target or enables the cursor with CURSOR.

OR
Combines two signed 32-bit integers using bitwise OR.

PEEK()
Returns the byte stored at a session memory address.

POKE
Writes a byte to a session memory address.

PRINT
Writes expressions to the terminal.

PRINTAT
Writes a character at a screen position without moving the cursor.

RANDOMIZE
Replaces the current random number generator with a new one.

READ
Reads successive DATA values into variables or array elements.

RELMOVEBLOCKSPRITE
Moves a block sprite relative to its current position.

REM
Marks the rest of a source line as a comment.

RENUM
Renumbers stored program lines as an abbreviation for RENUMBER.

RENUMBER
Renumbers stored program lines and updates explicit jump targets.

RESET
Restores the configured appearance and clears runtime data.

RESTORE
Resets the DATA pointer to the beginning.

RETURN
Returns to the statement following the most recent GOSUB call.

RIGHT$()
Returns a specified number of characters from the end of a string.

RND()
Returns a pseudorandom number from zero inclusive to one exclusive.

RUN
Clears runtime data and starts the stored program.

SAVE
Saves the stored BASIC program to a source file.

SCNCLR
Clears the screen as an alternative spelling of CLS.

SCROLL
Controls automatic scrolling or shifts the text area.

SGN()
Returns the sign of a number.

SIN()
Returns the sine of an angle in radians.

SLEEP
Waits for the remaining time in a millisecond interval.

SOFT
Makes RESET retain the stored program while clearing runtime data.

SQR()
Returns the square root of a number.

SRND()
Returns a pseudorandom integer within specified bounds.

STEP
Specifies the increment of a FOR loop.

STOP
Pauses a numbered program so that CONT can resume it.

STR$()
Converts a numeric value to a string.

SUB
Identifies a subroutine call in the spaced GO SUB form.

TAB()
Positions printed output at a specified column.

TAN()
Returns the tangent of an angle in radians.

THEN
Introduces the branch taken when an IF condition is true.

TO
Specifies a FOR loop limit or forms the spaced GO TO jump.

VAL()
Converts a numeric string to a number.

WINDOW
Clears the screen and selects the number of text rows.

^
Raises a number to a power.
