VAL

Convert numeric text to a number you can use in calculations and comparisons.

Try VAL at the prompt

VAL(text)

text can be a quoted string, a string variable such as A$, or a string expression such as MID$(A$,5). VAL interprets the text as a single number. You can use the result anywhere a numeric expression is accepted.

Enter these lines separately at the Ready. prompt.

A$="0044"
PRINT A$
PRINT VAL(A$)
PRINT VAL(A$)+6

The three PRINT commands display 0044, 44 and 50. The conversion leaves A$ intact, so you can keep the original spelling for display and use the numeric value for arithmetic. Keep identifiers such as postal codes and serial numbers as strings when their leading zeros matter.

Accepted number formats

CallValueResult type
VAL("44")4432-bit integer
VAL(" +44 ")4432-bit integer
VAL("-4.5")−4.5Double-precision floating point
VAL("44.0")44Double-precision floating point
VAL("1.25e-2")0.0125Double-precision floating point
VAL("2147483648")2147483648Double-precision floating point

Plain signed or unsigned integers from −2147483648 through 2147483647 return a 32-bit integer. Decimal notation, exponent notation and integers outside that range return a floating-point value if the result is finite. Very large integers and many decimal fractions can be rounded to the nearest representable floating-point value.

Use a decimal point and omit digit-grouping separators regardless of your system locale. Surrounding spaces are allowed. An exponent begins with E or e and can have a sign. The result type in the table describes VAL itself. Assigning it to a variable follows ABL's variable rules. For example, N%=VAL("4.9") stores 4 because a percent-suffixed variable truncates toward zero.

Read a number or a quit command

Use INPUT N when every response should be numeric. ABL asks again after invalid numeric input. Use INPUT A$ when the same prompt accepts text commands as well as numbers. Check for the text command before converting the remaining response.

10 INPUT "ENTER A PRICE OR Q TO QUIT";PRICE$
20 IF PRICE$="Q" THEN 70
30 PRICE=VAL(PRICE$)
40 IF PRICE<0 THEN 80
50 PRINT "TOTAL WITH 25 PERCENT TAX ";PRICE*1.25
60 GOTO 10
70 END
80 PRINT "PRICE MUST BE ZERO OR MORE"
90 GOTO 10

Enter 20 to see a total of 25, or uppercase Q to exit. Enter the response without quotes. The program checks the allowed price range after conversion. A malformed number such as twenty stops this example at line 30 with a runtime error. Use numeric INPUT when you want ABL to handle retries automatically.

Extract a number from a text record

When a string contains a label or a unit, extract the numeric field before calling VAL. For a fixed format such as RPM=1500, MID$ can take everything after the four-character prefix RPM=.

10 READ RECORD$
20 RPM=VAL(MID$(RECORD$,5))
30 PRINT RPM/60;" REVOLUTIONS PER SECOND"
40 DATA "RPM=1500"

This displays 25 revolutions per second. MID$ supplies "1500" to VAL, while RECORD$ still holds the full record. This example assumes each record starts with RPM= followed by a numeric field.

Understand conversion errors

VAL expects the entire string to describe one number. An invalid conversion stops the current command or program. In a numbered program, the error identifies the line that called VAL.

CallWhat to check
VAL(44)Type mismatch: expected a string. The argument is already numeric, so use it directly.
VAL("") or VAL(" ")A number needs at least one digit. If blank has a meaning in your program, handle it before converting.
VAL("3,5") or VAL("1,000")Use "3.5" for a fraction and "1000" for a thousand.
VAL("44kg") or VAL("2+3")Extract the numeric field from labeled text. Write arithmetic as a BASIC expression outside the string.
VAL("NaN"), VAL("Infinity") or VAL("1e400")The conversion requires a finite number within the floating-point range.

Invalid numeric strings report Illegal function call: VAL requires a numeric string. A valid zero, such as VAL("0"), returns 0.

Convert back to text with STR$

Use STR$ when you need the string representation of a number, for example to build a label. You can place the two conversions on either side of a calculation.

TEXT$="0044"
RESULT$=STR$(VAL(TEXT$)+1)
PRINT "NEXT VALUE: ";RESULT$

This displays NEXT VALUE: 45. STR$(VAL("0044")) returns "44". Keep the original string if you need to preserve padding, a leading plus sign, or a particular decimal format.
