Block sprites

The ability to use terminal characters as sprites.

Back to the language reference

CREATEBLOCKSPRITE

CREATEBLOCKSPRITE num, x, y, asc
num
The sprite's ID, a signed 32-bit integer. Use the same ID again to update its position and character. If sprites overlap, the highest ID is drawn on top.
x, y
The column and row, starting at (0, 0) in the top-left corner. Both coordinates accept any signed 32-bit integer. Sprites outside the current screen are hidden.
asc
A PETSCII character code from 0 to 255, such as ASC("A"). The sprite uses the current text color when you issue the command.

A block sprite covers one screen cell. Moving it reveals the character underneath in its original color.

Try these commands one at a time in direct mode. The last command moves sprite 1, changes its character to B, and reveals the dot.

PRINTAT 5, 3, ASC(".")
CREATEBLOCKSPRITE 1, 5, 3, ASC("A")
CREATEBLOCKSPRITE 1, 6, 3, ASC("B")

MOVEBLOCKSPRITE

MOVEBLOCKSPRITE num, x, y[, asc]

Moves an existing sprite to the given column and row, revealing the screen cell it previously covered. Supply asc to change the sprite's character, or omit it to keep the current character. The sprite keeps its color. An unknown sprite ID produces an error.

Example program

The sprite travels across a line of text and then moves off-screen, leaving the whole line visible. SLEEP on line 100 sets an 80-millisecond interval between steps.

10 CLS
20 T$ = "THE TEXT STAYS IN PLACE"
30 FOR X = 0 TO LEN(T$) - 1
40 PRINTAT X, 8, ASC(MID$(T$, X + 1, 1))
50 NEXT X
60 CREATEBLOCKSPRITE 1, -1, 8, ASC("*")
70 FOR X = 0 TO LEN(T$) - 1
80 MOVEBLOCKSPRITE 1, X, 8
90 IF X = 10 THEN MOVEBLOCKSPRITE 1, X, 8
100 SLEEP 80
120 NEXT X
130 MOVEBLOCKSPRITE 1, -1, 8
140 END
