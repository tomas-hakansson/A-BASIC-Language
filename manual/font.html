Find a character in memory

The terminal font occupies addresses 53248 through 55295 in ABL's session memory. There are 256 character codes, from 0 to 255, and each code gets eight consecutive bytes. Each byte controls one row of an 8 × 8 pixel character. Row 0 is the top row and row 7 is the bottom row.

address = 53248 + 8 * code + row

Use ASC("A") to get the terminal character code for A. It returns 65, so the bytes for A are at addresses 53768 through 53775. PEEK(address) reads a row and POKE address,value replaces it with an integer from 0 to 255.

Each column has a bit weight. Add the weights of the pixels you want to turn on. Pixels with a zero bit show the cell's background color.

Pixel column, left to right01234567
Bit weight1286432168421

A byte of 0 clears the row and 255 fills it. A byte of 24 lights the two middle pixels because 16 + 8 = 24. Its pattern is ...##..., where # is an on pixel and . is an off pixel.

Choose characters for games

All 256 character codes, from 0 to 255, can be edited with POKE, including letters, numbers, punctuation and the space character. In both built-in fonts, codes 0–31, 91, 93–96 and 123–255 start blank and are available for your own game characters and animation frames. Code 250 in the example below is one of these spare slots. Codes 97–122 contain lowercase letter shapes. Choose spare slots your program has not already used, and pass their codes to CHR$, PRINTAT or CREATEBLOCKSPRITE to display them. Editing a code changes its appearance everywhere it is used, including existing text and sprites.

Change an existing character

Enter these commands one at a time at the ABL prompt. Save the top row of A in OLDROW, then draw a solid line across that row. The other seven rows keep their current pixel patterns.

ADDR = 53248 + 8 * ASC("A")
OLDROW = PEEK(ADDR)
PRINT "A"
POKE ADDR,255
PRINT "A"

The terminal redraws existing cells that use the edited character, so both printed copies of A show the solid top row. To change a different row, add its row number to ADDR. For example, ADDR + 7 points to the bottom row.

Write back the byte you saved to restore the top row.

POKE ADDR,OLDROW

Draw and print a custom symbol

Use a spare character code to add a symbol without replacing a letter. Code 250 starts blank in both built-in fonts and uses addresses 55248 through 55255. If your program already defines a symbol there, pick a different spare code. PEEK lets you inspect the eight bytes before writing them.

Sketch the symbol on an 8 × 8 grid and convert each row to a byte. For this heart, row 1 lights columns 1, 2, 5 and 6, so its value is 64 + 32 + 4 + 2 = 102. Read the eight values from top to bottom, including the blank rows.

Row  Pixels    Byte
  0  ........     0
  1  .##..##.   102
  2  ########   255
  3  ########   255
  4  .######.   126
  5  ..####..    60
  6  ...##...    24
  7  ........     0

Enter the numbered lines in an empty program and type RUN. The loop reads one byte per row from DATA and writes it to the corresponding address. CHR$(250) produces the character for code 250. You can store it in a string variable and use it in PRINT like any other character.

10 CODE = 250
20 ADDR = 53248 + 8 * CODE
30 FOR ROW = 0 TO 7
40 READ PIXELS
50 POKE ADDR + ROW,PIXELS
60 NEXT ROW
70 HEART$ = CHR$(CODE)
80 PRINT "LIVES ";HEART$;HEART$;HEART$
90 DATA 0,102,255,255,126,60,24,0

Keep or restore your changes

Font edits are shared by direct commands and running programs. They survive RUN and NEW within the session. Keep the symbol's DATA and POKE loop in your saved BASIC program so it can define the symbol again when run in a new session.

To restore an edited character, save each row you plan to change with PEEK and write the saved bytes back with POKE. To clear a symbol you created in a blank slot, write 0 to all eight of its rows. Restarting ABL or switching between Commodore 64 and Commodore PET under Tools → Options... reloads the entire font and discards any edits.

See the POKE command reference for general memory access.
